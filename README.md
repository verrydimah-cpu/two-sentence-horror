A tiny Node program that writes one horror story of exactly two sentences — a voice in the wall that repeats the narrator one second before he speaks, until the morning it says something he has not thought of yet — to `entry.txt` in the output directory, ready for the judge.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
